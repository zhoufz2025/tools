#### 2.3.3 浮动盈亏计算详细说明

##### 2.3.3.1 历史数据移植（clientProfitLossHisToCur）

**功能**：首次上线浮动盈亏功能时，将历史存量数据从份额表（`tbdxfundshare`）计算后写入份额扩展表（`tbdxfundshareext`）

**触发条件**：
- 参数`ReleaseDate`等于当前交易日

**处理逻辑**：

**步骤1：查询需要移植的数据**

```sql
-- 查询份额表中有份额但份额扩展表中不存在的记录
SELECT in_client_no, bank_acc, bank_no, prd_code, tot_vol
FROM tbdxfundshare{表后缀}
WHERE tot_vol > 0.001
  AND (in_client_no, bank_acc, bank_no, prd_code) NOT IN (
      SELECT in_client_no, bank_acc, bank_no, prd_code 
      FROM tbdxfundshareext{表后缀}
  )
  AND ta_code = {TACODE}
ORDER BY in_client_no, bank_acc, prd_code
```

**步骤2：计算投资开始日期**

对于每条记录，需要从交易确认表中查找投资开始日期（`beg_date`）。逻辑如下：

**累计份额的初始值来源**：

累计份额的初始值来自份额表（`tbdxfundshare`）的`tot_vol`字段，即当前客户在该产品上的总份额。

```sql
-- 查询份额表中的当前总份额
SELECT in_client_no, bank_acc, bank_no, prd_code, tot_vol
FROM tbdxfundshare{表后缀}
WHERE tot_vol > 0.001
  AND (in_client_no, bank_acc, bank_no, prd_code) NOT IN (
      SELECT in_client_no, bank_acc, bank_no, prd_code 
      FROM tbdxfundshareext{表后缀}
  )
  AND ta_code = {TACODE}
```

**计算逻辑**：

1. **初始化累计份额**：从份额表获取当前总份额（`tot_vol`）作为累计份额的初始值
   
   ```java
   double dTotVol = transVar.getTotVol();  // 从份额表获取的tot_vol
   ```
   
2. **从当前日期往前倒推**：查询交易确认表和非交易过户表，按确认日期倒序排列
   
   ```sql
   SELECT busin_code, cfm_date, cfm_vol, targ_prd_code, targ_cfm_vol, conv_dir
   FROM (
       SELECT prd_code, bank_no, busin_code, cfm_date, cfm_vol, targ_prd_code, 
              targ_cfm_vol, conv_dir, status, '0' flag
       FROM tbdxfundtranscfm{表后缀}
       WHERE in_client_no = {客户内部编号}
         AND bank_acc = {银行账号}
         AND cfm_date <= {当前交易日}
       UNION ALL
       SELECT prd_code, bank_no, busin_code, cfm_date, cfm_vol, targ_prd_code,
              targ_cfm_vol, conv_dir, status, '1' flag
       FROM tbdxfunduntradetransfer00
       WHERE in_client_no = {客户内部编号}
         AND bank_acc = {银行账号}
         AND cfm_date <= {当前交易日}
         AND trans_flag = '1'
   ) a
   WHERE (prd_code = {产品代码} OR (targ_prd_code = {产品代码} AND busin_code = '136'))
     AND bank_no = {银行代码}
     AND status IN ('6', '7', '8', 'A')
     AND busin_code IN ({BUSINCODE})
   ORDER BY cfm_date DESC
   ```
   
3. **按日期分组累计计算份额变化**：
   
   - **购买类交易**（130、122、139、137、127、134、144、143等）：累计份额减少
     
     ```java
     dTotVol = dTotVol - cfm_vol;  // 购买类交易减少份额
     ```
   - **赎回类交易**（124、142、138、136、128、135、145、198、163等）：累计份额增加
     
     ```java
     dTotVol = dTotVol + cfm_vol;  // 赎回类交易增加份额
     ```
   - **特殊处理**：
     - **转换入（136）**：如果目标产品代码为当前产品，使用`targ_cfm_vol`减少份额；否则使用`cfm_vol`增加份额
     - **非交易过户（133）**：根据`flag`字段判断是转入还是转出
   
4. **判断投资开始日期**：当累计份额小于等于0（或小于等于0.0001）时，该日期即为投资开始日期
   ```java
   if (dTotVol <= 0.0001) {
       return cfm_date;  // 返回投资开始日期
   }
   ```

**示例说明**：

假设当前份额表中的`tot_vol = 1000`（累计份额初始值），从当前日期往前查找：

- **日期1（最新）**：赎回200份 → 累计份额 = 1000 + 200 = 1200
- **日期2**：申购500份 → 累计份额 = 1200 - 500 = 700
- **日期3**：赎回300份 → 累计份额 = 700 + 300 = 1000
- **日期4**：申购1000份 → 累计份额 = 1000 - 1000 = 0 ✅ **投资开始日期**

因此，投资开始日期为日期4。

**步骤3：插入历史数据到份额扩展表**

```sql
-- 插入历史数据到份额扩展表

SELECT 
    in_client_no, bank_acc, bank_no, client_no, ta_code, prd_code,
    {投资开始日期}, 0.0, 0, 0.0, 0.0,

    -- 认购确认金额
    SUM(CASE busin_code WHEN '130' THEN cfm_amt ELSE 0.0 END),
    -- 申购金额
    SUM(CASE busin_code WHEN '122' THEN cfm_amt ELSE 0.0 END),
    -- 定投金额
    SUM(CASE busin_code WHEN '139' THEN cfm_amt ELSE 0.0 END),
    -- 转换入金额（根据ProfitTransInMode参数）
    SUM(CASE busin_code WHEN '137' THEN 
        CASE WHEN {ProfitTransInMode}='1' THEN targ_cfm_vol*targ_nav+charge 
             ELSE cfm_vol*nav+charge END 
        ELSE 0.0 END),
    -- 转托管入金额
    SUM(CASE WHEN (busin_code='127' OR (busin_code='126' AND conv_dir='1')) 
        THEN cfm_vol*nav+charge ELSE 0.0 END),
    -- 非交易过户入金额
    SUM(CASE WHEN (busin_code='134' AND frozen_cause<>'9') THEN cfm_vol*nav+charge
             WHEN (busin_code='134' AND frozen_cause='9') THEN (amt+charge)
             ELSE 0.0 END),
    -- 份额强增折算金额
    SUM(CASE busin_code WHEN '144' THEN 
        CASE WHEN cfm_amt>0 THEN cfm_amt ELSE cfm_vol*nav+charge END 
        ELSE 0.0 END),
    -- 赎回金额
    SUM(CASE WHEN busin_code IN ('124','163') THEN cfm_amt
             WHEN busin_code='198' THEN 
                 CASE WHEN {SUM_198_INCOME_MODE}='1' THEN cfm_vol-amt 
                      ELSE cfm_amt+vol END
             ELSE 0.0 END),
    -- 强制赎回金额
    SUM(CASE busin_code WHEN '142' THEN cfm_amt ELSE 0.0 END),
    -- 转换出金额
    SUM(CASE WHEN busin_code IN ('138','136') AND cfm_amt>=0.001 THEN cfm_amt
             WHEN busin_code IN ('138','136') AND cfm_amt<0.001 THEN 
                 CASE WHEN {PROFIT_TRANSFER_OUT_CHARGE}='Y' THEN cfm_vol*nav
                      ELSE cfm_vol*nav-charge END
             ELSE 0.0 END),
    -- 转托管出金额
    SUM(CASE WHEN (busin_code='128' OR (busin_code='126' AND conv_dir='0')) 
        THEN cfm_vol*nav-charge ELSE 0.0 END),
    -- 非交易过户出金额
    SUM(CASE WHEN busin_code IN ('135','133') THEN cfm_vol*nav-charge ELSE 0.0 END),
    -- 分红份额折算金额
    SUM(CASE busin_code WHEN '143' THEN cfm_vol*nav ELSE 0.0 END),
    -- 分红份额
    SUM(CASE busin_code WHEN '143' THEN cfm_vol ELSE 0.0 END),
    -- 分红金额
    SUM(CASE busin_code WHEN '143' THEN (cfm_amt+cont_frozen_amt) ELSE 0.0 END),
    -- 产品终止金额
    SUM(CASE WHEN busin_code IN ('150','151') THEN cfm_amt ELSE 0.0 END),
    -- 份额强减折算金额
    SUM(CASE busin_code WHEN '145' THEN 
        CASE WHEN cfm_amt>0 THEN cfm_amt ELSE cfm_vol*nav-charge END 
        ELSE 0.0 END),
    0.0, 0.0,  -- total_cost, total_income初始为0
    -- 累积投入手续费
    SUM(CASE WHEN busin_code IN ('130','122','139','137','127','134','144') 
                  OR (busin_code='126' AND conv_dir='1') 
             THEN charge ELSE 0 END)
FROM tbdxfundtranscfm{表后缀}
WHERE cfm_date >= {投资开始日期}
  AND cfm_date < {当前交易日}
  AND in_client_no = {客户内部编号}
  AND bank_acc = {银行账号}
  AND bank_no = {银行代码}
  AND prd_code = {产品代码}
  AND status IN ('6', '7', '8', 'A')
  AND busin_code IN ('130','122','139','137','127','126','134','133','144',
                     '124','142','138','136','128','135','143','150','151','145','198','163')
GROUP BY in_client_no, bank_acc, bank_no, client_no, ta_code, prd_code
```

##### 2.3.3.2 当前浮动盈亏计算（clientProfitLossCalc）

**功能**：根据当日确认的交易流水（`tbdxfundtranscfm`）计算浮动盈亏，更新份额扩展表（`tbdxfundshareext`）

**处理逻辑**：

**步骤0：历史分红上日净值统计（genHisNav）**

**功能**：统计历史分红的上日净值，用于持仓收益计算（模式3：分红平摊持仓成本模式）

**启用条件**：
- 参数`HOLD_PROFIT_LOSS_SUM`等于"3"（分红平摊持仓成本模式）

**处理逻辑**：

1. **获取上一交易日**：通过`PubApiFactory.getPrevTaDate()`获取上一交易日（`prevTaTransDate`）

2. **清空临时表**：清空临时表`tbdxfundnavtmp`中当前TA的数据
   ```sql
   DELETE FROM tbdxfundnavtmp WHERE ta_code = {TACODE}
   ```

3. **初始化产品记录**（根据`hisFlag`参数判断）：
   
   **当`hisFlag = "0"`时**（正常日终处理）：
   
   从每日收益表（`tbdxfunddailyprofitloss`）中查询上一交易日有现金分红（`busin_code='143'`且`cfm_amt>0`且`cfm_vol=0`）的产品，获取其上日净值：
   
   ```sql
   INSERT INTO tbdxfundnavtmp 
     (ta_code, cfm_date, prd_code, prev_nav, prev_cfm_date)
   SELECT a.ta_code, 
          {当前交易日}, 
          a.prd_code, 
          CASE WHEN MAX(a.nav) = 0 THEN 1 ELSE MAX(a.nav) END, 
          {上一交易日}
   FROM tbdxfunddailyprofitloss{表后缀} a
   WHERE a.ta_code = {TACODE}
     AND a.record_date = {上一交易日}
     AND EXISTS (
         SELECT 1 
         FROM tbdxfundtranscfm{表后缀} b 
         WHERE b.ta_code = {TACODE}
           AND b.cfm_date = {当前交易日}
           AND b.busin_code = '143'
           AND b.prd_code = a.prd_code
           AND b.cfm_amt > 0
           AND b.cfm_vol = 0
     )
     AND NOT EXISTS (
         SELECT 1 
         FROM tbdxfundnavtmp c 
         WHERE c.ta_code = a.ta_code
           AND c.prd_code = a.prd_code
           AND c.cfm_date = {当前交易日}
     )
   GROUP BY a.ta_code, a.prd_code
   ```
   
   **当`hisFlag = "1"`时**（历史数据移植）：
   
   从交易确认表（`tbdxfundtranscfm`）中查询历史现金分红记录，获取分红时的净值：
   
   ```sql
   INSERT INTO tbdxfundnavtmp 
     (ta_code, cfm_date, prd_code, prev_nav, prev_cfm_date)
   SELECT a.ta_code, 
          a.cfm_date, 
          a.prd_code, 
          CASE WHEN MAX(a.nav) = 0 THEN 1 ELSE MAX(a.nav) END, 
          0
   FROM tbdxfundtranscfm{表后缀} a
   WHERE a.busin_code = '143'
     AND a.ta_code = {TACODE}
     AND a.cfm_amt > 0
     AND a.cfm_vol = 0
     AND NOT EXISTS (
         SELECT 1 
         FROM tbdxfundnavtmp c 
         WHERE c.ta_code = a.ta_code
           AND c.prd_code = a.prd_code
           AND c.cfm_date = a.cfm_date
     )
   GROUP BY ta_code, prd_code, cfm_date
   ```

**涉及表**：
- 输入：`tbdxfunddailyprofitloss{表后缀}`（每日收益表）、`tbdxfundtranscfm{表后缀}`（交易确认表）
- 输出：`tbdxfundnavtmp`（临时净值表）

**说明**：
- 该步骤仅在持仓收益计算模式为"3"（分红平摊持仓成本模式）时执行
- 临时表`tbdxfundnavtmp`用于存储分红时的上日净值，供后续计算持仓收益时使用
- 在`calBagAmt3`方法中会使用该临时表的数据计算分红带走成本

**步骤1：创建临时表并汇总当日交易流水**

创建临时表`tbdxfundshareext{表后缀}_{TACODE}`，汇总当日交易确认流水：

```sql

    in_client_no, bank_acc, bank_no, client_no, ta_code, prd_code, trans_date, nav,
    allot_amt,           -- 认购金额
    allot_cfm_amt,       -- 认购确认金额
    purchase_amt,        -- 申购金额(含预约购买金额)
    auto_sub_amt,        -- 定投金额
    conv_in_amt,         -- 转换入金额
    trust_in_amt,        -- 转托管入金额
    assign_in_amt,       -- 非交易过户入金额
    force_add_amt,       -- 份额强增折算金额
    red_amt,             -- 赎回金额(含预约赎回金额)
    force_red_amt,       -- 强制赎回金额
    conv_out_amt,        -- 转换出金额
    trust_out_amt,       -- 转托管出金额
    assign_out_amt,      -- 非交易过户出金额
    div_vol_amt,         -- 分红份额折算金额
    div_vol,             -- 分红份额
    div_amt,             -- 分红金额
    clear_end_amt,       -- 产品终止金额
    force_sub_amt,       -- 份额强减折算金额
    total_cost,          -- 累积投入资金
    total_income,        -- 累积收益计算
    total_charge,        -- 累积投入手续费
    bag_vol              -- 落袋份额
)
SELECT 
    in_client_no, bank_acc, bank_no, client_no, ta_code, prd_code,
    {当前交易日}, 0.0,
    -- 认购确认金额（业务代码130）
    SUM(CASE busin_code WHEN '130' THEN cfm_amt ELSE 0.0 END),
    -- 申购金额（业务代码122）
    SUM(CASE busin_code WHEN '122' THEN cfm_amt ELSE 0.0 END),
    -- 定投金额（业务代码139）
    SUM(CASE busin_code WHEN '139' THEN cfm_amt ELSE 0.0 END),
    -- 转换入金额（业务代码137）
    -- 根据参数ProfitTransInMode判断：
    --   0: 使用targ_cfm_vol*targ_nav+charge
    --   1: 使用cfm_vol*nav+charge
    SUM(CASE busin_code WHEN '137' THEN 
        CASE WHEN {ProfitTransInMode}='1' THEN targ_cfm_vol*targ_nav+charge 
             ELSE cfm_vol*nav+charge END 
        ELSE 0.0 END),
    -- 转托管入金额（业务代码127或126且conv_dir='1'）
    SUM(CASE WHEN (busin_code='127' OR (busin_code='126' AND conv_dir='1')) 
        THEN cfm_vol*nav+charge ELSE 0.0 END),
    -- 非交易过户入金额（业务代码134或133）
    SUM(CASE WHEN (busin_code='134' AND frozen_cause<>'9') THEN cfm_vol*nav+charge
             WHEN (busin_code='134' AND frozen_cause='9') THEN (amt+charge)
             ELSE 0.0 END),
    -- 份额强增折算金额（业务代码144，根据参数控制）
    SUM(CASE busin_code WHEN '144' THEN 
        CASE WHEN cfm_amt>0 THEN cfm_amt ELSE cfm_vol*nav+charge END 
        ELSE 0.0 END),
    -- 赎回金额（业务代码124、163、198）
    SUM(CASE WHEN busin_code IN ('124','163') THEN cfm_amt
             WHEN busin_code='198' THEN 
                 CASE WHEN {SUM_198_INCOME_MODE}='1' THEN cfm_vol-amt 
                      ELSE cfm_amt+vol END
             ELSE 0.0 END),
    -- 强制赎回金额（业务代码142）
    SUM(CASE busin_code WHEN '142' THEN cfm_amt ELSE 0.0 END),
    -- 转换出金额（业务代码138、136）
    SUM(CASE WHEN busin_code IN ('138','136') AND cfm_amt>=0.001 THEN cfm_amt
             WHEN busin_code IN ('138','136') AND cfm_amt<0.001 THEN 
                 CASE WHEN {PROFIT_TRANSFER_OUT_CHARGE}='Y' THEN cfm_vol*nav
                      ELSE cfm_vol*nav-charge END
             ELSE 0.0 END),
    -- 转托管出金额（业务代码128或126且conv_dir='0'）
    SUM(CASE WHEN (busin_code='128' OR (busin_code='126' AND conv_dir='0')) 
        THEN cfm_vol*nav-charge ELSE 0.0 END),
    -- 非交易过户出金额（业务代码135、133）
    SUM(CASE WHEN busin_code IN ('135','133') THEN cfm_vol*nav-charge ELSE 0.0 END),
    -- 分红份额折算金额（业务代码143）
    SUM(CASE busin_code WHEN '143' THEN cfm_vol*nav ELSE 0.0 END),
    -- 分红份额（业务代码143）
    SUM(CASE busin_code WHEN '143' THEN cfm_vol ELSE 0.0 END),
    -- 分红金额（业务代码143）
    SUM(CASE busin_code WHEN '143' THEN (cfm_amt+cont_frozen_amt) ELSE 0.0 END),
    -- 产品终止金额（业务代码150、151）
    SUM(CASE WHEN busin_code IN ('150','151') THEN cfm_amt ELSE 0.0 END),
    -- 份额强减折算金额（业务代码145，根据参数控制）
    SUM(CASE busin_code WHEN '145' THEN 
        CASE WHEN cfm_amt>0 THEN cfm_amt ELSE cfm_vol*nav-charge END 
        ELSE 0.0 END),
    0.0, 0.0,  -- total_cost, total_income初始为0
    -- 累积投入手续费
    SUM(CASE WHEN busin_code IN ('130','122','139','137','127','134','144') 
                  OR (busin_code='126' AND conv_dir='1') 
             THEN charge ELSE 0 END),
    -- 落袋份额
    SUM(CASE WHEN busin_code IN ('124','142','138','136','128','135','150','151','198','163','133')
                  OR (busin_code='126' AND conv_dir<>'1')
             THEN cfm_vol
             WHEN busin_code='145' THEN 
                 CASE WHEN {ZERO_BAG_VOL_145}='Y' THEN 0 ELSE cfm_vol END
             ELSE 0 END)
FROM tbdxfundtranscfm{表后缀}
WHERE cfm_date = {当前交易日}
  AND ta_code = {TACODE}
  AND status IN ('6', '7', '8', 'A')
  AND busin_code IN ('130','122','139','137','127','126','134','133','144',
                     '124','142','138','136','128','135','143','150','151','145','198','163')
  -- 实时赎回过滤（如果启用）
  AND (reserve2 <> '1' OR busin_code NOT IN ({RealTimeBusinCodes}))
GROUP BY in_client_no, bank_acc, bank_no, client_no, ta_code, prd_code
```

**步骤8：计算平均成本**

```sql
-- 更新当日购买份额（amt1字段）

    SELECT in_client_no, prd_code 
    FROM tbdxfundtranscfm{表后缀}
    WHERE cfm_date = {当前交易日}
      AND ta_code = {TACODE}
      AND status IN ('6', '7', '8', 'A')
      AND busin_code IN ({BUSINCODE})
)

-- 计算平均成本
UPDATE tbdxfundshareext{表后缀} x
SET last_date = {当前交易日},
    avg_price = COALESCE((
        SELECT CASE b.tot_vol WHEN 0.0 THEN 0 
                ELSE (a.avg_price * (b.tot_vol - a.amt1) + 
                      COALESCE((c.allot_amt + c.allot_cfm_amt + c.purchase_amt + 
                                c.auto_sub_amt + c.conv_in_amt + c.trust_in_amt +
                                c.assign_in_amt + c.force_add_amt), 0.00)) / b.tot_vol 
               END avg_price
        FROM tbdxfundshareext{表后缀} a
        LEFT JOIN tbdxfundshare{表后缀} b
          ON a.prd_code = b.prd_code
         AND a.in_client_no = b.in_client_no
         AND a.bank_acc = b.bank_acc
         AND a.bank_no = b.bank_no
        LEFT JOIN tbdxfundshareext{表后缀}_{TACODE} c
          ON a.prd_code = c.prd_code
         AND a.in_client_no = c.in_client_no
         AND a.bank_acc = c.bank_acc
         AND a.bank_no = c.bank_no
        WHERE a.in_client_no = x.in_client_no
          AND a.prd_code = x.prd_code
          AND a.bank_acc = x.bank_acc
          AND a.bank_no = x.bank_no
    ), 0.00)
WHERE x.amt1 > 0.001
  AND x.ta_code = {TACODE}
```

**计算公式**：

- **流入金额** = 认购确认金额 + 申购金额 + 定投金额 + 转换入金额 + 转托管入金额 + 非交易过户入金额 + 份额强增折算金额
- **流出金额** = 赎回金额 + 强制赎回金额 + 转换出金额 + 转托管出金额 + 非交易过户出金额 + 分红金额 + 份额强减折算金额 + 产品终止金额
- **累计成本（total_cost）** = 流入金额
- **累计收益（total_income）** = 流出金额
- **平均成本（avg_price）** = (上期平均成本 × (当前份额 - 当日购买份额) + 当日购买金额) / 当前份额

**涉及表**：

- 输入：`tbdxfundtranscfm{表后缀}`（交易确认表）、`tbdxfunduntradetransfer00`（非交易过户表）
- 临时表：`tbdxfundshareext{表后缀}_{TACODE}`（临时表）
- 输出：`tbdxfundshareext{表后缀}`（份额扩展表）

##### 2.3.3.4 持仓收益计算（TaskFundHold210511）

**功能**：计算持仓收益（持仓均价、持仓收益、持仓收益率等）

**启用条件**：
- 参数`HOLD_PROFIT_LOSS_SUM`不为"NO"
- 参数`HOLD_RELEASE_DATE`小于当前交易日

**计算模式**（根据`HOLD_PROFIT_LOSS_SUM`参数）：
- **模式1（HOLD_PROFIT_LOSS_SUM=1）**：基础模式
  - 持仓收益 = (最新净值 - 持仓均价) × 当前总份额
  - 持仓收益率 = (持仓收益 / 持仓成本) × 100
- **模式2（HOLD_PROFIT_LOSS_SUM=2）**：宁波银行模式
  - 持仓收益 = 当前份额 × 最新净值 - 持仓成本 + 持仓现金红利
  - 持仓收益率 = (持仓收益 / 持仓成本) × 100
- **模式3（HOLD_PROFIT_LOSS_SUM=3）**：分红平摊持仓成本模式
  - 持仓收益 = 当前份额 × 最新净值 - 持仓成本
  - 持仓收益率 = (持仓收益 / 持仓成本) × 100
