# 基金浮动盈亏查询数据总结

## 一、概述

本文档基于`T110383NewAction.java`类，总结基金浮动盈亏查询（交易代码：T110383）所查询的数据及其来源和计算逻辑。

## 二、查询的数据表

### 2.1 主要数据表

#### 1. 份额表（tbdxfundshare）
- **表名**：`tbdxfundshare{表后缀}`
- **用途**：查询客户当前持有的基金份额
- **主要字段**：
  - `tot_vol`：总份额
  - `frozen_vol`：冻结份额
  - `long_frozen_vol`：长期冻结份额
  - `other_frozen`：其他冻结
  - `income_frozen`：收益冻结
  - `income_onway`：在途收益
  - `ystdy_tot_vol`：昨日总份额
  - `div_mode`：分红方式

#### 2. 份额扩展表（tbdxfundshareext）
- **表名**：`tbdxfundshareext{表后缀}`
- **用途**：存储份额的扩展信息，用于计算当前浮动盈亏
- **查询逻辑**：按`in_client_no`、`bank_acc`、`bank_no`、`prd_code`查询，按`beg_date`降序排列取第一条
- **作用**：作为浮动盈亏计算的基础数据

#### 3. 历史累计份额扩展表（tbdxfundshareextaccum）
- **表名**：`tbdxfundshareextaccum{表后缀}`
- **用途**：存储历史累计浮动盈亏的扩展信息
- **查询条件**：当参数`PROFIT_LOSS_SUM_FLAG`的第2位为"1"时查询
- **作用**：计算历史累计浮动盈亏

#### 4. 资金表（tbdxfundsquare）
- **表名**：`tbdxfundsquare{表后缀}`
- **用途**：查询在途资金记录（份额为0但仍有在途资金的场景）
- **查询条件**：
  - `status != '2' and status !='7'`
  - `busin_code in ('150', '151', '124', '142', '163', '143')` 或 `(busin_code in ('120','122','130','139') and liqu_dir ='1')`

#### 5. 交易申请表（tbdxfundtransreq）
- **表名**：`tbdxfundtransreq{表后缀}`
- **用途**：
  - 查询在途交易金额
  - 查询快速赎回冻结金额（余额宝产品）
  - 查询累积在途赎回份额
- **主要查询字段**：
  - `trans_code`：交易代码
  - `status`：状态（'0','1','5','P','6','A','Z','C'等）
  - `amt`：金额
  - `vol`：份额
  - `liqu_status`：清算状态

#### 6. 份额扩展明细表（tbdxfundshareextend）
- **表名**：`tbdxfundshareextend{表后缀}`
- **用途**：查询在途购买金额、预期赎回金额、赎回收益等
- **主要字段**：
  - `buy_amt_onway`：在途购买金额
  - `red_exp_amt`：预期赎回金额
  - `red_income`：赎回收益

#### 7. 每日盈亏表（tbdxfunddailyprofitloss）
- **表名**：`tbdxfunddailyprofitloss{表后缀}`
- **用途**：查询每日收益信息
- **主要字段**：
  - `record_date`：记录日期
  - `nav_date`：净值日期
  - `end_nav`：结束净值
  - `income_new`：新收益
  - `reserve1`：完成标识（'1'表示已完成）

#### 8. TA份额明细表（tbdxfundtasharedetail）
- **表名**：`tbdxfundtasharedetail{表后缀}`
- **用途**：查询持有期产品的未解锁份额（FOF产品、短期理财产品）
- **主要字段**：
  - `ta_available_vol`：TA可用份额
  - `frozen_vol`：冻结份额
  - `allow_red_date`：允许赎回日期

#### 9. 智能定投协议表（tbdxfundsmartautoinvest）
- **表名**：`tbdxfundsmartautoinvest`
- **用途**：查询智能定投协议份额
- **主要字段**：
  - `tot_invest_vol`：总投资份额
  - `tot_invest_cost`：总投资成本
  - `tot_invest_income`：总投资收益
  - `finish_flag`：完成标志（'1'表示已完成）

### 2.2 辅助数据来源

#### 1. 产品信息
- **来源**：产品缓存（`FullDxFundProductCache`、`FullDxFundLocalProductCache`）
- **主要字段**：
  - `prd_code`：产品代码
  - `prd_name`：产品名称
  - `nav`：净值
  - `nav_date`：净值日期
  - `prd_attr`：产品属性
  - `prd_status`：产品状态
  - `risk_level`：风险等级
  - `div_mode`：分红方式
  - `control_flag`：控制标志

#### 2. TA信息
- **来源**：TA信息缓存（`DxFundTAInfoCache`）
- **主要字段**：
  - `ta_code`：TA代码
  - `ta_name`：TA名称
  - `ta_shortname`：TA简称
  - `ta_status`：TA状态

## 三、查询逻辑

### 3.1 主查询逻辑

根据`TotVolFlag`参数决定查询范围：

1. **TotVolFlag = "2"**：有份额+在途
   - 查询`tbdxfundshare`（份额表）
   - UNION查询`tbdxfundsquare`（资金表）

2. **TotVolFlag = "1"**：仅返回有份额记录
   - 只查询`tbdxfundshare`（份额表）
   - 条件：`tot_vol > 0.0001`

3. **TotVolFlag = 其他值**：
   - 如果`PROFIT_LOSS_SUM_FLAG`的第2位为"1"：查询历史累计浮动盈亏（`tbdxfundshareextaccum`）
   - 否则：查询份额表（`tbdxfundshare`）

### 3.2 查询条件

主要查询条件包括：
- `in_client_no`：客户内部编号
- `bank_acc`：银行账号（支持真实卡查询虚拟卡）
- `bank_no`：银行代码
- `ta_code`：TA代码（可选）
- `prd_code`：产品代码（可选）
- `prd_codes`：产品代码列表（可选）
- `hold_share_type`：持仓类型（空-过滤投顾和持仓类，1-查询投顾，其他-查询持仓）
- `advisor_flag`：投顾标志（用于持仓交易隔离）

## 四、浮动盈亏计算

### 4.1 当前浮动盈亏计算

#### 数据来源
- 从`tbdxfundshareext`表获取份额扩展信息（`DxFundShareExt`对象）

#### 计算服务
- 调用`IDxFundProfitLossCalc`服务的`calc`方法进行计算
- 服务名称：`IConstant.SVRNAME_ProfitLoss`

#### 返回字段
- `CurValue`：当前市值
- `TotCost`：累计投资金额
- `TotDivAmt`：累积现金红利
- `TotDivVol`：累计份额红利
- `TotIncomeAmt`：累计收益金额
- `ProfitLoss`：浮动盈亏
- `ProfitLossRate`：盈亏率
- `UnitCost`：单位成本
- `StartDate`：收益计算开始时间
- `EndDate`：收益计算结束时间

#### 特殊处理
- 如果份额扩展记录的`end_date > 0`（已结束），浮动盈亏置为0

### 4.2 历史累计浮动盈亏计算

#### 数据来源
- 从`tbdxfundshareextaccum`表获取历史累计份额扩展信息

#### 计算服务
- 同样调用`IDxFundProfitLossCalc`服务的`calc`方法

#### 返回字段
- `HisTotCost`：累计投资金额
- `HisTotDivAmt`：累积现金红利
- `HisTotDivVol`：累计份额红利
- `HisTotIncomeAmt`：累计收益金额
- `HisProfitLoss`：浮动盈亏
- `HisProfitLossRate`：盈亏率
- `HisUnitCost`：单位成本
- `HisStartDate`：收益计算开始时间
- `HisEndDate`：收益计算结束时间

### 4.3 持仓收益计算

#### 启用条件
- 参数`HOLD_PROFIT_LOSS_SUM`不为"NO"
- 参数`HOLD_RELEASE_DATE`小于当前交易日
- 总份额大于0

#### 返回字段
- `AvgHoldPrice`：平均持仓价格
- `HoldProfitLoss`：持仓收益
- `HoldProfitLossRate`：持仓收益率
- `HoldTotCost`：持仓总成本

### 4.4 昨日/今日收益计算

#### 计算逻辑
根据参数`PROFIT_LOSS_INCONEW`和`ASSET_VIEW_NEW`决定：

1. **按物理日期计算收益**（`ASSET_VIEW_NEW = "1"`）：
   - **有夜间行情**（`NIGHTFILE_PROFIT = "1"`）：
     - 昨日收益日期 = 物理日期-1
     - 今日收益日期 = 物理日期
     - 需要校验是否为TA工作日
   - **无夜间行情**：
     - 昨日收益日期 = 上一TA工作日
     - 今日收益日期 = 0

2. **调用每日盈亏服务**：
   - 服务：`IDxFundDailyProfitLossSerivce.calc`
   - 查询`tbdxfunddailyprofitloss`表
   - 返回`IncomeNew`（新收益）和`Reserve1`（完成标识）

#### 返回字段
- `YstdyIncome`：昨日收益
- `YstdyDate`：昨日收益日期
- `YstdyCompleteFlag`：昨日收益完成标识
- `TodayIncome`：今日收益
- `TodayDate`：今日收益日期
- `TodayCompleteFlag`：今日收益完成标识
- `LastIncomeNew`：最新收益
- `LastIncomeNewDate`：最新收益日期

### 4.5 日涨幅计算

#### 计算逻辑
根据参数`PROFIT_LOSS_DAYRATE`和`DAYRATE_NAV`：

1. **DAYRATE_NAV = "1"**：使用净值计算
   - 日涨幅 = (当前净值 - 上一交易日净值) / 上一交易日净值

2. **DAYRATE_NAV != "1"**：使用累计净值计算
   - 日涨幅 = (当前累计净值 - 上一交易日累计净值) / 上一交易日累计净值

#### 数据来源
- 从产品行情表（`tbdxfundprddaily`）获取净值信息

## 五、份额信息查询

### 5.1 总份额（TotVol）
- **来源**：`tbdxfundshare.tot_vol`

### 5.2 可用份额（UseVol）

#### 计算公式
```
UseVol = TotVol - FrozenVol - LongFrozenVol - OtherFrozen - IncomeFrozen [+ BuyAmtOnway - RedExpAmt - RedIncome]
```

#### 特殊处理

1. **在途购买处理**（参数`T110383_USE_VOL_CALC_ONWAY`）：
   - 如果为"1"：可用份额 = 总份额 - 各种冻结 + (在途购买金额 - 预期赎回金额 - 赎回收益)
   - 如果为"0"：可用份额 = 总份额 - 各种冻结

2. **智能定投份额**（参数`HaveSmartInvest = "1"`）：
   - 从`tbdxfundsmartautoinvest`表查询未完成的智能定投协议份额
   - 如果参数`QUERY_USEVOL_SUB_SMARTINVEST_VOL = "1"`：可用份额减去智能定投份额

3. **持有期产品未解锁份额**（FOF产品、短期理财产品）：
   - 从`tbdxfundtasharedetail`表查询未解锁份额
   - 可用份额 = 可用份额 - 未解锁份额
   - 如果计算结果小于0，置为0

### 5.3 冻结份额（FrozenVol）
- **计算公式**：`FrozenVol = FrozenVol + LongFrozenVol + OtherFrozen`
- **来源**：`tbdxfundshare`表

### 5.4 总市值（TotPrdValue）
- **计算公式**：`TotPrdValue = TotVol × NAV`（四舍五入到2位小数）

### 5.5 在途收益（IncomeOnway）
- **来源**：`tbdxfundshare.income_onway`

## 六、在途资金查询

### 6.1 在途购买金额（OnwayAmt）

#### 查询条件
- `trans_code`在`REALBUYTRANSCODE`参数配置的交易代码列表中
- `status` in ('0','1','5','P','6','A','Z','C')
- 如果参数`ONWAY_LIQU = "1"`：`liqu_status = '2'`（转账中）

#### 特殊处理
- 如果参数`DEAL120PARTCFM = "1"`：
  - 对于`status='A'`且`liqu_status='4'`的交易，如果确认金额`cfm_amt >= 0`，使用确认金额，否则使用申请金额

### 6.2 在途赎回份额（AllRedSum）
- **查询条件**：`trans_code = '110202'` 且 `status in ('0','1','5')`
- **字段**：`vol`（份额）

### 6.3 资金表在途金额（SquareAmt）
- **来源**：`tbdxfundsquare`表
- **查询条件**：
  - `status != '2' and status !='7'`
  - `busin_code in ('150', '151', '124', '142', '163', '143')` 或 `(busin_code in ('120','122','130','139') and liqu_dir ='1')`
  - 过滤投顾调仓赎回的账户（通过`amt_flag`过滤）

## 七、余额宝产品特殊处理

### 7.1 余额宝标识
- 判断条件：产品控制标志`CurrencyPrdMode = "1"`

### 7.2 可用份额计算
- 可用份额 = 可用份额 + 在途收益（`IncomeOnway`）

### 7.3 总资产计算
- **计算公式**：`TotPrdValue = UseVol + FrozenVol - 快速过户冻结部分`
- **快速过户冻结部分**：
  - 从`tbdxfundtransreq`表查询
  - 条件：`trans_code = '110415'`（快速过户）
  - `status in ('0','1','5')`
  - 金额 = `amt1 + amt`

### 7.4 总资产（TotValue）
- **余额宝**：`TotValue = TotPrdValue + SquareAmt`
- **非余额宝**：`TotValue = TotPrdValue + OnwayAmt + IncomeOnway`

## 九、关键参数说明

### 9.1 查询控制参数
- `PROFIT_LOSS_SUM_FLAG`：浮动盈亏汇总标志（第1位控制当前浮动盈亏，第2位控制历史累计浮动盈亏）
- `HOLD_PROFIT_LOSS_SUM`：持仓收益汇总标志
- `HOLD_RELEASE_DATE`：持仓收益上线日期
- `PROFIT_LOSS_INCONEW`：是否返回昨日/今日收益
- `ASSET_VIEW_NEW`：是否按物理日期计算收益
- `NIGHTFILE_PROFIT`：是否有夜间行情
- `PROFIT_LOSS_DAYRATE`：是否返回日涨幅
- `DAYRATE_NAV`：日涨幅计算方式（1-净值，0-累计净值）

### 9.2 份额计算参数
- `T110383_USE_VOL_CALC_ONWAY`：可用份额是否计算在途购买
- `HaveSmartInvest`：是否有智能定投
- `QUERY_USEVOL_SUB_SMARTINVEST_VOL`：可用份额是否减去智能定投份额
- `SUPP_USEVOL_BY_TASHAREDETAIL`：是否支持按TA份额明细计算可用份额

### 9.3 在途资金参数
- `T100699_RE_ONWAYAMT`：是否返回在途金额
- `REALBUYTRANSCODE`：真实购买交易代码列表
- `ONWAY_LIQU`：在途资金是否考虑清算状态
- `DEAL120PARTCFM`：是否处理120部分确认

## 十、数据流程总结

### 10.1 查询流程
1. **预处理**：获取客户信息、分表号、数据库类型
2. **产品列表**：根据条件获取产品列表（普通产品、余额宝产品）
3. **主查询**：根据`TotVolFlag`决定查询份额表或资金表
4. **分页查询**：对查询结果进行分页处理
5. **明细查询**：对每条记录查询详细信息

### 10.2 明细查询流程
1. **产品信息**：从产品缓存获取产品基本信息
2. **份额信息**：查询份额表获取份额数据
3. **浮动盈亏**：查询份额扩展表，调用浮动盈亏计算服务
4. **在途资金**：查询交易申请表和资金表获取在途资金
5. **每日收益**：查询每日盈亏表获取昨日/今日收益
6. **汇总计算**：计算总资产等汇总字段

### 10.3 浮动盈亏计算流程
1. **获取份额扩展数据**：从`tbdxfundshareext`表查询
2. **调用计算服务**：`IDxFundProfitLossCalc.calc`
3. **获取计算结果**：包括浮动盈亏、累计收益等
4. **特殊处理**：已结束产品浮动盈亏置0
5. **历史累计**：如果启用，从`tbdxfundshareextaccum`表查询并计算

## 十一、注意事项

1. **分表处理**：所有表都根据客户内部编号进行分表，通过`DxFundShardingUtil.getTableNumByInClientNo`获取表后缀
2. **虚拟卡支持**：支持真实卡查询虚拟卡数据，通过`entity_bank_acc`字段关联
3. **持仓交易隔离**：通过`advisor_flag`字段区分投顾和持仓类交易
4. **余额宝特殊逻辑**：余额宝产品的总资产计算逻辑与其他产品不同
5. **持有期产品**：FOF产品和短期理财产品需要考虑未解锁份额
6. **智能定投**：需要考虑智能定投协议占用的份额
