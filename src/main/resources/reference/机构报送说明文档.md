# 机构报送功能说明文档

## 一、机构报送背景

机构报送是基金代销系统向监管机构定期报送业务数据的重要功能模块。根据监管要求，代销机构需要定期向监管机构报送以下数据：

1. **产品信息**：代销产品的详细信息，包括产品代码、名称、类型、风险等级等
2. **交易确认汇总**：各类交易（认购、申购、赎回、转换等）的确认汇总数据
3. **份额保有量汇总**：客户持有产品份额的汇总统计
4. **销售收入汇总**：各类手续费收入的汇总统计

系统通过批量任务自动提取、汇总和生成报送文件，并支持文件传输到监管机构系统。

## 三、流程介绍

机构报送功能通过批量任务实现，整个流程分为四个阶段：

### 3.1 批量任务配置

批量任务配置在 `tbschedulejob` 和 `tbscheduletask` 表中：

- **批量作业代码**：J210632（机构报送）
- **父作业**：J210014（数据汇总）
- **执行顺序**：放在数据汇总后面执行

### 3.2 批量节点流程

#### 3.2.1 节点一：交易片区机构报送数据提取（DXFUND210632）

**功能代码**：DXFUND210632  
**实现位置**：`lcpt-dxfund-trans\lcpt-dxfund-batch-bootstrap`  
**实现类**：`T210632HSAdapter`

**功能说明**：
- 从交易片区提取机构报送所需的基础数据
- 处理交易相关的原始数据，为后续汇总做准备

**功能说明**：
- 从交易片区的分表中提取份额数据和交易确认数据
- 将数据汇总到同步表，生成文件传输到公共片区
- 支持并发处理，提高数据提取效率

**主要处理逻辑**：

1. **并发任务配置**：
   - 根据参数 `JGBS_SHARESYNC_TABLE` 决定是否执行份额数据提取任务
   - 始终执行交易确认数据提取任务
   - 使用线程池并发执行多个任务（线程数：`PROCNUM210632`，队列大小：`QUEUESIZE210632`）

2. **份额数据提取**（`BNShareHZStatsTask`）：
   - 从交易片区分表 `tbdxfundshare1` ~ `tbdxfundshare16` 提取份额数据
   - 插入到同步表 `tbdxfundbscssharesync`
   - 只提取份额大于0.0001的记录

3. **交易确认数据提取**（`BNTransConfirmHZStatsTask`）：
   - 判断是否为月报日期（根据参数 `JGBS_MONTH_DAY` 和系统工作日计算）
   - 如果不是月报日期，不提取数据
   - 从交易片区分表 `tbdxfundtranscfm1` ~ `tbdxfundtranscfm16` 提取上月交易确认数据
   - 插入到同步表 `tbdxfundbscstranscfmsync`

4. **文件生成和传输**：
   - 使用 `StandardFileWriter` 将同步表数据生成文件
   - 文件传输到公共片区
   - 公共片区会导入这些文件到对应的表

**关键参数配置**：

**数据流向图**：
```

│   文件传输
│   ↓ [文件导入]

    ↓ [生成文件]
    文件传输
    ↓ [文件导入]
    tbdxfundbscstranscfmsync (公共片区)
    ↓ [在PUB210632节点使用]

```

**执行流程**：
1. **初始化**：获取系统参数，初始化线程池
2. **并发执行**：
   - 任务1：份额数据提取（可选，根据参数控制）
   - 任务2：交易确认数据提取（必选）
3. **数据提取**：每个任务从分表提取数据到同步表
4. **文件生成**：将同步表数据生成标准格式文件
5. **文件传输**：文件传输到公共片区
6. **结果汇总**：汇总所有任务的执行结果，如有失败则抛出异常

**功能说明**：
- 从公共片区提取机构报送所需的数据
- 提取产品信息、份额数据、交易确认数据、销售收入数据等
- 支持并发处理，通过Task机制提高执行效率

**主要处理逻辑**：

1. **参数获取和初始化**（`transRequest`方法）：
   - `JGBS_MONTH_DAY`：报送月份日期（默认1号）
   - `JGBS_PRD_TYPES`：报送产品类型
   - `JGBS_DAILY_SQUARE`：是否支持T+0.5清算
   - 计算是否为月报日期（根据系统工作日数判断）
   - **计算year和month**（用于月报数据汇总和清理）：
     - IF 当前月份 = 1月 THEN
     -     year = 上年（当前年份-1）
     -     month = 12月
     - ELSE
     -     year = 当年（当前年份）
     -     month = 上月（当前月份-1）
     - END IF
     - 例如：如果当前是2024年3月，则year=2024，month=2
     -      如果当前是2024年1月，则year=2023，month=12

2. **数据清理**（`clearData`方法）：
   - 根据参数 `T210632_CLEAR_DATA_TRUNCATE` 决定使用truncate或delete方式
   - 清理产品信息表、份额表、交易确认表、服务费表、手续费表

3. **加载其他系统数据**（`loadOtherSysData`方法）：
   - 支持基金资管分开部署场景
   - 通过 `IOrgSubmitLoadService` 接口加载其他系统的报送数据

4. **本地数据提取**（`loadLocalData`方法）：
   - **直接执行**：产品信息提取、服务费数据提取、手续费数据提取
   - **并发执行**：份额数据提取、交易确认数据提取（通过Task机制）
   - **后续处理**：分级基金产品代码转换

**详细SQL执行逻辑**：

1. **数据清理**（`clearData`方法）：
   ```sql
   -- 方式1：使用DELETE（默认方式）
   DELETE FROM tbdxfundbscsproduct;
   
   -- 如果支持T+0.5清算，不删除份额表
   IF NOT 支持T+0.5清算 THEN
       DELETE FROM tbdxfundbscsshare;
   END IF;
   
   -- 如果是月报日期，删除月报相关表
   IF 是月报日期 THEN
       DELETE FROM tbdxfundbscstranscfm;
       DELETE FROM tbdxfundbscshisservicefeehz;
       DELETE FROM tbdxfundbscshissxfhz;
   END IF;
   
   -- 方式2：使用TRUNCATE（根据参数T210632_CLEAR_DATA_TRUNCATE控制）
   IF 使用TRUNCATE方式 THEN
       TRUNCATE TABLE tbdxfundbscsproduct;
       IF NOT 支持T+0.5清算 THEN
           TRUNCATE TABLE tbdxfundbscsshare;
       END IF;
       IF 是月报日期 THEN
           TRUNCATE TABLE tbdxfundbscstranscfm;
           TRUNCATE TABLE tbdxfundbscshisservicefeehz;
           TRUNCATE TABLE tbdxfundbscshissxfhz;
       END IF;
   END IF;
   ```

7. **分级基金产品代码转换**（`loadLocalData`方法中，在所有数据提取完成后）：
   ```sql
   -- 查询分级基金主产品代码
   SELECT b.reserve2 main_prd_code, COUNT(1) num, MAX(a.prd_code) prd_code
   FROM tbdxfundbscsproduct a, tbdxfundproduct b
   WHERE a.prd_code = b.prd_code
     AND substr(b.control_flag,82,1) = '1'
     AND b.reserve2 <> ' '
   GROUP BY b.reserve2;
   
   -- 对每个主产品代码进行处理
   FOR EACH 主产品代码 IN 查询结果 LOOP
       IF 主产品代码已存在于tbdxfundbscsproduct THEN
           -- 删除子产品记录
           DELETE FROM tbdxfundbscsproduct a
           WHERE EXISTS (
               SELECT 1 FROM tbdxfundproduct b
               WHERE b.prd_code = a.prd_code
                 AND substr(b.control_flag,82,1) = '1'
                 AND b.reserve2 = 主产品代码
           )
           AND a.prd_code <> 主产品代码;
       ELSE
           -- 更新第一个子产品代码为主产品代码
           UPDATE tbdxfundbscsproduct
           SET prd_code = 主产品代码
           WHERE prd_code = 第一个子产品代码;
           
           -- 删除其他子产品记录
           DELETE FROM tbdxfundbscsproduct a
           WHERE EXISTS (
               SELECT 1 FROM tbdxfundproduct b
               WHERE b.prd_code = a.prd_code
                 AND substr(b.control_flag,82,1) = '1'
                 AND b.reserve2 = 主产品代码
           )
           AND a.prd_code <> 主产品代码;
       END IF;
   END LOOP;
   ```

8. **并发任务执行**（`concurrentProcess`方法）：
   ```java
   // 创建线程池
   RestlessThreadExcutor processor = new RestlessThreadExcutor(

   );
   
   // 启动线程池
   processor.start();
   
   // 并发执行所有Task
   FOR EACH task IN map LOOP
       task.setContext(context);
       task.setTaskName(task类名);
       WHILE true LOOP
           result = processor.tryExecute(task);
           IF result THEN

           ELSE

   END LOOP;
   
   // 停止线程池并等待所有任务完成

   // 汇总执行结果
   IF 有任务失败 THEN
       抛出异常;
   END IF;
   ```

**关键参数配置**：

| 参数代码 | 参数名称 | 默认值 | 说明 |
|---------|---------|--------|------|
| JGBS_MONTH_DAY | 报送月份日期 | 1 | 每月第几个TA工作日进行月报报送 |
| JGBS_PRD_TYPES | 报送产品类型 | 0 | 需要报送的产品类型（逗号分隔） |
| JGBS_DAILY_SQUARE | 是否支持T+0.5清算 | 0 | 0-否，1-是 |
| JGBS_SHARESYNC_TABLE | 是否使用shareqry表 | 0 | 0-使用同步表，1-使用tbdxfundshareqry表 |
| T210632_CLEAR_DATA_TRUNCATE | 是否使用truncate清理数据 | 0 | 0-使用delete，1-使用truncate |
| PROCNUM210632 | 并发线程数 | 5 | Task并发执行线程数 |
| QUEUESIZE210632 | 线程队列大小 | 5 | 每个线程的等待队列大小 |
| HIDE_632_BUSINCODE | 隐藏业务代码 | 空 | 需要隐藏的业务代码（逗号分隔） |
| USE_PRD_STATUS | 是否使用产品状态筛选 | 0 | 0-否，1-是 |
| JGBS_EXPIRE_PRD | 是否统计到期产品 | 0 | 0-不统计，1-统计 |

**数据流向图**：

**执行流程**：
1. **参数获取**：获取系统参数，计算月报日期标志
2. **数据清理**：根据参数选择truncate或delete方式清理历史数据
3. **加载其他系统数据**：通过接口加载其他系统的报送数据（如需要）
4. **产品信息提取**：从tbdxfundbsproduct提取产品信息
5. **并发任务配置**：
   - 根据参数决定是否添加份额数据提取Task
   - 如果是月报日期，添加交易确认数据提取Task
6. **并发执行Task**：
   - 份额数据提取：从同步表导入文件数据，提取到机构报送份额表
   - 交易确认数据提取：从同步表导入文件数据，提取到机构报送交易确认表
7. **服务费和手续费提取**：如果是月报日期，提取服务费和手续费数据
8. **分级基金处理**：将分级基金子产品代码转换为主产品代码
9. **结果汇总**：汇总所有Task的执行结果，如有失败则抛出异常

#### 3.2.3 节点三：机构报送数据汇总（PUB210633）

**实现类**：`T210633HSAdapter`

**功能说明**：

- 生成份额保有量汇总、交易确认汇总、销售收入汇总

**主要处理逻辑**：
1. **数据校验**：
   - 校验是否有外币基金产品需要报送
   - 校验汇率数据是否完整

2. **汇率处理**：
   - 获取外币转人民币汇率

1. **数据清理**（`clearData`方法）：

4. **销售收入汇总**（`sellinfoHZStatistic`方法）：
   ```sql
   -- 步骤1：先处理外币产品汇率转换（在汇总前转换）
   IF 启用外币转换 THEN
       -- 转换服务费表中外币金额
       UPDATE tbdxfundbscshisservicefeehz a
       SET sale_fee = (
           SELECT ROUND(a.sale_fee * r.exchange_rate, 2)
           FROM tbdxfundbsexchangerate r, tbdxfundproduct b
           WHERE r.report_date_type = '1'
             AND r.curr_type = b.curr_type
             AND a.prd_code = b.prd_code
           GROUP BY r.exchange_rate
       ),
       trailing_fee = (
           SELECT ROUND(a.trailing_fee * r.exchange_rate, 2)
           FROM tbdxfundbsexchangerate r, tbdxfundproduct b
           WHERE r.report_date_type = '1'
             AND r.curr_type = b.curr_type
             AND a.prd_code = b.prd_code
           GROUP BY r.exchange_rate
       )
       WHERE EXISTS (
           SELECT 1 FROM tbdxfundbsexchangerate r, tbdxfundproduct b
           WHERE r.report_date_type = '1'
             AND r.curr_type = b.curr_type
             AND a.prd_code = b.prd_code
       );
       
       -- 转换手续费表中外币金额
       UPDATE tbdxfundbscshissxfhz a
       SET trans_fee = (
           SELECT ROUND(a.trans_fee * r.exchange_rate, 2)
           FROM tbdxfundbsexchangerate r, tbdxfundproduct b
           WHERE r.report_date_type = '1'
             AND r.curr_type = b.curr_type
             AND a.prd_code = b.prd_code
           GROUP BY r.exchange_rate
       )
       WHERE EXISTS (
           SELECT 1 FROM tbdxfundbsexchangerate r, tbdxfundproduct b
           WHERE r.report_date_type = '1'
             AND r.curr_type = b.curr_type
             AND a.prd_code = b.prd_code
       );
   END IF;
   
   -- 步骤2：汇总销售服务费和客户维护费
   WITH serviceFeeSql AS (
       -- 服务费转换成主代码
       SELECT CASE WHEN (substr(b.control_flag,82,1)='1' AND b.reserve2<>' ')
                   THEN b.reserve2 
                   ELSE a.prd_code END prd_code,
              a.sale_fee, a.trailing_fee
       FROM tbdxfundbscshisservicefeehz a, tbdxfundproduct b
       WHERE a.prd_code = b.prd_code
   ),
   sxfSql AS (
       -- 手续费转换成主代码
       SELECT a.sum_date, a.sum_flag, a.internal_branch, a.client_type,
              CASE WHEN (substr(b.control_flag,82,1)='1' AND b.reserve2<>' ')
                   THEN b.reserve2 
                   ELSE a.prd_code END prd_code,
              a.busin_code, a.branch_no, a.ta_code, a.trans_fee, a.open_fee, 
              a.prd_type, b.bank_no
       FROM tbdxfundbscshissxfhz a, tbdxfundproduct b
       WHERE a.prd_code = b.prd_code
   ),
   sxfSumsql AS (
       -- 手续费数据汇总
       SELECT prd_code, busin_code, 
              SUM(trans_fee) trans_fee, 
              SUM(open_fee) open_fee
       FROM sxfSql
       GROUP BY prd_code, busin_code
   )
   -- 插入销售服务费和客户维护费
   INSERT INTO tbdxfundbsincomeinfo 
   (bank_no, prd_kind, sale_charge_inocme, trailing_charge_income, year, month)
   SELECT '000' bank_no,
          b.prd_kind,
          SUM(a.sale_fee) sale_charge_inocme,
          SUM(a.trailing_fee) trailing_charge_income,
          计算后的year year,
          计算后的month month
   FROM serviceFeeSql a
   LEFT JOIN tbdxfundbscsproduct b ON a.prd_code = b.prd_code
   GROUP BY b.prd_kind;
   
   -- 步骤3：汇总各业务手续费（按业务代码分类）
   -- Oracle/PostgreSQL使用MERGE，MySQL使用UPDATE+INSERT
   -- 认购手续费：busin_code IN ('120','130')
   -- 申购手续费：busin_code IN ('122','139')
   -- 赎回手续费：busin_code IN ('124','142')
   -- 转换手续费：busin_code IN ('136','137','138')
   
   -- Oracle/PostgreSQL方式
   MERGE INTO tbdxfundbsincomeinfo a
   USING (
       SELECT b.prd_kind,
              SUM(trans_fee) current_charge_income,
              SUM(CASE WHEN busin_code IN ('120','130') THEN trans_fee ELSE 0 END) sub_charge_income,
              SUM(CASE WHEN busin_code IN ('122','139') THEN trans_fee ELSE 0 END) allot_chargr_income,
              SUM(CASE WHEN busin_code IN ('124','142') THEN trans_fee ELSE 0 END) red_charge_income,
              SUM(CASE WHEN busin_code IN ('136','137','138') THEN trans_fee ELSE 0 END) transfer_charge_income
       FROM sxfSumsql m
       LEFT JOIN tbdxfundbscsproduct p ON m.prd_code = p.prd_code
       GROUP BY p.prd_kind
   ) b
   ON (a.prd_kind = b.prd_kind AND a.year = 计算后的year AND a.month = 计算后的month)
   WHEN MATCHED THEN
       UPDATE SET a.current_income = a.sale_charge_inocme + a.trailing_charge_income + b.current_charge_income,
                  a.current_charge_income = b.current_charge_income,
                  a.sub_charge_income = b.sub_charge_income,
                  a.allot_chargr_income = b.allot_chargr_income,
                  a.red_charge_income = b.red_charge_income,
                  a.transfer_charge_income = b.transfer_charge_income
   WHEN NOT MATCHED THEN
       INSERT (bank_no, prd_kind, current_charge_income, sub_charge_income, 
               allot_chargr_income, red_charge_income, transfer_charge_income, year, month)
       VALUES ('000', b.prd_kind, b.current_charge_income, b.sub_charge_income,
               b.allot_chargr_income, b.red_charge_income, b.transfer_charge_income, 计算后的year, 计算后的month);
   
   -- 步骤4：计算本年累计收入
   UPDATE tbdxfundbsincomeinfo a
   SET year_charge_income = (
           SELECT SUM(current_charge_income)
           FROM tbdxfundbsincomeinfo b
           WHERE b.bank_no = a.bank_no
             AND b.prd_kind = a.prd_kind
             AND b.year = a.year
             AND b.month <= a.month
           GROUP BY b.bank_no, b.prd_kind
       ),
       year_sub_charge = (
           SELECT SUM(sub_charge_income)
           FROM tbdxfundbsincomeinfo b
           WHERE b.bank_no = a.bank_no
             AND b.prd_kind = a.prd_kind
             AND b.year = a.year
             AND b.month <= a.month
           GROUP BY b.bank_no, b.prd_kind
       ),
       -- ... 其他累计字段类似
   WHERE a.year = 计算后的year AND a.month = 计算后的month;
   
   -- 步骤5：计算总收入
   UPDATE tbdxfundbsincomeinfo
   SET current_income = current_charge_income + sale_charge_inocme + 
                        trailing_charge_income + other_income,
       year_income = year_charge_income + year_sale_charge + 
                     year_trailing_charge + year_other_income
   WHERE year = 计算后的year AND month = 计算后的month;
   ```

5. **汇率获取**（`getExchangeRate`方法）：
   ```sql
   -- 从tbdxfundexchangerateinfo获取汇率并插入到tbdxfundbsexchangerate
   -- 日报汇率：取小于当前日期的最大汇率
   FOR EACH 外币币种 IN 外币币种列表 LOOP
       SELECT * FROM tbdxfundexchangerateinfo
       WHERE curr_type = 外币币种
         AND targ_curr_type = '156'  -- 人民币
         AND trans_date < 当前日期
       ORDER BY trans_date DESC
       LIMIT 1;
       
       -- 插入日报汇率
       INSERT INTO tbdxfundbsexchangerate 
       (report_date_type, curr_type, exchange_rate)
       VALUES ('0', 外币币种, spot_ex_buying_rate);
       
       -- 如果是月报，获取上月最后汇率
       IF 是月报日期 THEN
           SELECT * FROM tbdxfundexchangerateinfo
           WHERE curr_type = 外币币种
             AND targ_curr_type = '156'
             AND trans_date < 本月1号
             AND trans_date >= 上月1号
           ORDER BY trans_date DESC
           LIMIT 1;
           
           -- 插入月报汇率
           INSERT INTO tbdxfundbsexchangerate 
           (report_date_type, curr_type, exchange_rate)
           VALUES ('1', 外币币种, spot_ex_buying_rate);
       END IF;
   END LOOP;
   ```

#### 3.2.4 节点四：机构报送数据生成并发送（PUB210634）

**实现类**：`T210634HSAdapter`

**功能说明**：
- 根据汇总数据生成报送文件
- 将文件发送到监管机构系统

**主要处理逻辑**：
1. **参数校验**：

   - 生成销售收入汇总文件（从 `tbdxfundbsincomeinfo` 表）

**详细SQL执行逻辑**：

```sql

WHERE reg_date = 登记日期

-- 生成销售收入汇总文件（从tbdxfundbsincomeinfo表）
```

## 五、注意事项

1. **数据清理**：210632节点清理数据时，注意不要删除月报需要关联的数据
2. **产品代码转换**：分级基金需要转换为主代码，避免主键冲突
3. **多法人支持**：注意bank_no和seller_code的正确处理
4. **外币产品**：需要配置汇率数据，否则无法正确汇总
5. **报送日期**：根据参数配置的报送日期，只在指定日期生成和发送文件
6. **产品状态筛选**：已停售的产品默认不报送，可通过参数控制
7. **到期产品统计**：可通过参数控制是否统计到期产品
