# 综合理财系统文件读写规则与配置说明

## 一、概述

本文档基于`GeneralFileReader.java`和`GeneralFileWriter.java`两个核心类的分析，详细说明综合理财系统中通用文件的读写规则和个性化配置方法。

### 1.1 核心类说明

- **GeneralFileReader**: 负责从服务器获取文件、解析文件内容并导入到数据库
- **GeneralFileWriter**: 负责从数据库查询数据、格式化并生成文件，然后发送到服务器

### 1.2 文件处理流程

#### 文件读取流程（GeneralFileReader）
1. 初始化配置（从数据库加载文件类型、传输配置、字段映射）
2. 从服务器获取文件（支持FTP/SFTP/主机接口/本地文件）
3. 解析文件内容（支持定长和分隔符两种格式）
4. 数据导入数据库
5. 记录文件信息到`tbgenfileinfo`表

#### 文件写入流程（GeneralFileWriter）
1. 初始化配置（从数据库加载文件类型、传输配置、字段映射）
2. 从数据库查询数据
3. 格式化数据（根据字段配置格式化）
4. 生成文件（包含文件头、数据行、文件尾）
5. 发送文件到服务器
6. 记录文件信息到`tbgenfileinfo`表

## 二、核心配置表结构

### 2.1 tbgenfiletype（通用文件类型表）

文件类型的基础配置表，定义文件的基本属性。

|--------|------|------|

| file_dir | VARCHAR2(1) | 文件方向：0-日终导出 1-日启导出 2-日终导入 3-日启导入 |
| table_name | VARCHAR2(32) | 对应表名称（导入时写入的表，导出时查询的表） |
| remark | VARCHAR2(1000) | 备注 |
| sql_script | VARCHAR2(250) | SQL脚本（用于数据过滤条件，支持YYYYMMDD占位符） |
| split_str | VARCHAR2(32) | 分隔符（ASCII码，如124表示\|，为空表示定长格式） |
| templet | VARCHAR2(20) | 接口模板（用于区分不同的业务场景） |
| skip_line | INTEGER | 跳过行数（文件开头跳过的行数） |
| end_content | VARCHAR2(512) | 文件结束内容（遇到该内容停止读取） |

| channel | VARCHAR2(1) | 渠道（暂未启用） |

**主键**: (ta_code, file_type, file_dir, channel)

## 三、文件读取规则（GeneralFileReader）

### 3.1 文件获取方式

根据`tbgenfiletransfer.transfer_mode`字段配置不同的获取方式：

#### 方式1：主机接口（transfer_mode = 1）
- 通过主机报文接口获取文件
- 文件直接放到本地路径
- 需要配置`host_service`字段

#### 方式2：主机接口+SFTP（transfer_mode = 2）
- 先调用主机接口通知生成文件
- 然后通过SFTP从服务器获取文件
- 需要配置`host_service`和SFTP相关参数

#### 方式3：本地文件（transfer_mode = 3）
- 直接从本地路径读取文件
- 只需要校验文件是否存在

#### 方式4：FTP/SFTP（transfer_mode = 其他值）
- 通过FTP或SFTP从服务器获取文件
- 根据系统参数`290330.FtpType`决定使用FTP还是SFTP
- 需要配置服务器IP、端口、用户名、密码等

### 3.2 文件格式解析

#### 定长格式（split_str为空）
- 按照`tbgenfieldmap`中配置的字段长度顺序解析
- 支持字段类型：
  - **NUMBER**: 数字类型，支持小数位（通过scale配置）
  - **LONG**: 长整型
  - **CHAR**: 字符串类型

#### 分隔符格式（split_str不为空）
- 按照分隔符拆分字段
- 分隔符使用ASCII码表示（如124表示\|）
- 支持多个分隔符组合

### 3.3 数据导入规则

1. **清空原数据**：根据`sql_script`和`ta_code`条件清空目标表数据
2. **字段映射**：根据`tbgenfieldmap`配置映射文件字段到数据库字段
3. **键值转换**：如果配置了`key_no`，通过字典表进行值转换
4. **批量提交**：每2000条记录提交一次（可配置）
5. **空行处理**：自动跳过空行
6. **结束标识**：遇到`end_content`配置的内容时停止读取

### 3.4 特殊处理

- **文件编码**：根据`charset`字段配置读取文件编码（默认GBK）
- **跳过行数**：根据`skip_line`配置跳过文件开头的指定行数
- **空文件处理**：根据`empty_flag`决定是否允许空文件
- **销售商代码映射**：支持销售商代码的映射转换

## 四、文件写入规则（GeneralFileWriter）

### 4.1 文件生成流程

1. **查询数据**：根据`table_name`和`sql_script`查询数据
2. **格式化数据**：根据`tbgenfieldmap`配置格式化每条记录
3. **写入文件头**：从`tbgenfilecontent`读取文件头内容（position=1）
4. **写入数据行**：逐行写入格式化后的数据
5. **写入文件尾**：从`tbgenfilecontent`读取文件尾内容（position=2）
6. **记录信息**：将文件信息写入`tbgenfileinfo`表

### 4.2 数据格式化规则

#### 定长格式（split_str为空）
- 字符串类型：左对齐，右补空格（或根据字段长度配置）
- 数字类型：右对齐，前补0，支持小数位格式化
- 日期类型：为0时输出空格

#### 分隔符格式（split_str不为空）
- 字段之间用分隔符连接
- 字符串类型：不trim（可配置）
- 数字类型：格式化小数位
- 特殊处理：
  - 半角逗号转全角（机构报送场景）
  - 换行符和分隔符替换（机构报送场景）
  - 每行最后去掉分隔符（机构报送场景）

### 4.3 文件头尾处理

文件头和文件尾支持以下占位符替换：
- `YYYYMMDD`: 交易日期
- `HHMMSSNNN`: 日期时间（精确到毫秒）
- `HHMMSS`: 时间（精确到秒）
- `RECORDNUM`: 记录数（8位，前补0）

### 4.4 文件发送方式

#### 方式1：主机接口（transfer_mode = 1）
- 通过主机报文接口发送文件
- 发送成功后自动生成`.OK`文件并发送

#### 方式2：主机接口+SFTP（transfer_mode = 2）
- 先通过SFTP发送文件
- 然后调用主机接口通知

#### 方式3：本地文件（transfer_mode = 3）
- 文件移动到远程路径
- 生成OK文件（后缀可配置）

#### 方式4：FTP/SFTP（transfer_mode = 其他值）
- 根据系统参数决定使用FTP还是SFTP
- 支持生成OK文件（可配置）

### 4.5 特殊场景处理

#### 机构报送（templet = 'JGBS'）
- 支持多法人模式
- 特殊字段处理（半角逗号转全角、换行符替换等）
- 支持自定义文件编码

#### 片区文件处理
- 支持公共片区和交易片区的文件合并
- 支持从分布式文件系统下载片区文件
- 支持上传片区文件到分布式文件系统

#### 多法人模式
- 不同法人行使用不同目录
- 文件路径自动添加银行代码

### 5.1 配置新文件类型（导入场景）

#### 步骤1：配置文件类型（tbgenfiletype）

- `table_name`: 数据导入的目标表

**关键字段说明**：
- `transfer_mode`: 0-FTP/SFTP, 1-主机接口, 2-主机接口+SFTP, 3-本地文件

### 5.3 定长格式配置示例

对于定长格式文件，需要在`tbgenfieldmap`中配置字段长度和类型。系统会根据字段类型自动处理：

- **CHAR类型**：左对齐，右补空格
- **NUMBER类型**：右对齐，前补0，支持小数位
- **LONG类型**：右对齐，前补0

注意：定长格式需要在代码层面配置字段长度，`tbgenfieldmap`表中没有长度字段，长度信息在`GenField`对象中配置。

### 5.4 分隔符格式配置示例

对于分隔符格式文件，只需在`tbgenfiletype.split_str`中配置分隔符的ASCII码即可：

- `124`: \|
- `44`: ,
- `9`: Tab
- 多个分隔符：用逗号分隔，如`44,124`表示先按逗号再按竖线分隔

### 5.5 字典转换配置

如果需要对字段值进行字典转换：

1. 在`tbgenfieldmap.key_no`中配置字典键值
2. 系统会自动从字典表中查询对应的转换值
3. 支持正向转换（导出）和反向转换（导入）

### 5.6 按交易码过滤配置

如果文件需要按交易码过滤：

1. 在`tbgenfiletype.trans_code`中配置交易码
2. 在创建`GeneralFileReader`或`GeneralFileWriter`时传入交易码参数
3. 系统会自动过滤对应交易码的文件配置

## 六、常见配置场景

### 6.1 机构报送文件配置

机构报送文件通常使用分隔符格式，需要特殊处理：

1. **templet设置为'JGBS'**
2. **支持多法人模式**：根据`IFMS_MUTI_BANK`参数自动处理
3. **特殊字段处理**：
   - 半角逗号转全角
   - 换行符和分隔符替换
   - 每行最后去掉分隔符
4. **自定义编码**：通过`charset`字段配置

### 6.2 智能投顾文件配置

智能投顾文件支持片区处理：

1. **area_type配置**：'0'表示公共片区，'1'表示交易片区
2. **片区文件合并**：支持多个片区文件合并成一个文件
3. **分布式文件系统**：支持从分布式文件系统下载和上传

### 6.3 主机接口文件配置

使用主机接口方式时：

1. **transfer_mode设置为1或2**
2. **host_service必填**：配置主机报文接口代码
3. **自动生成OK文件**：发送成功后自动生成并发送OK文件

### 6.4 本地文件配置

使用本地文件方式时：

1. **transfer_mode设置为3**
2. **只需配置local_path**：remote_path用于移动文件的目标路径
3. **自动生成OK文件**：文件移动后自动生成OK文件

## 七、注意事项

### 7.1 文件编码

- 默认使用GBK编码
- 可通过`tbgenfiletype.charset`字段配置
- 支持GBK、UTF-8等常见编码

### 7.2 空文件处理

- `empty_flag='0'`：允许空文件，如果文件不存在或记录数为0，不报错
- `empty_flag='1'`：不允许空文件，如果文件不存在或记录数为0，会报错

### 7.3 文件路径

- 本地路径和远程路径支持相对路径和绝对路径
- 路径不存在时会自动创建
- 多法人模式下，路径会自动添加银行代码

### 7.4 文件命名

- 文件名规则支持`YYYYMMDD`占位符
- 系统会自动替换为实际日期
- 支持其他自定义占位符（需代码支持）

### 7.5 性能优化

- 批量提交：每2000条记录提交一次（可配置）
- 大文件处理：支持文件拆分（通过`single_file_num`配置）
- 片区文件：支持并行处理多个片区文件

## 九、总结

综合理财系统的文件读写功能通过配置表的方式实现了高度的灵活性和可扩展性。通过配置`tbgenfiletype`、`tbgenfiletransfer`、`tbgenfieldmap`、`tbgenfilecontent`等表，可以快速实现各种文件格式的读写需求，无需修改代码。

关键配置点：
1. **文件类型配置**：定义文件的基本属性和格式
2. **传输配置**：定义文件的获取和发送方式
3. **字段映射**：定义文件字段与数据库字段的对应关系
4. **文件头尾**：定义文件的固定头和尾内容

通过合理的配置，可以支持定长格式、分隔符格式、多种传输方式、字典转换等各种复杂场景。
